# Reglas del proyecto `shorty-api`

- Este proyecto usa **Python 3.10+**, **FastAPI**, **SQLAlchemy 2.x** y **`uv`**.
- El código interno (archivos, funciones, clases, tablas y endpoints) va en **inglés técnico**.
- La documentación (`README.md`) y los comentarios orientados al usuario van en **español**.
- Nunca guardes contraseñas, tokens ni rutas absolutas fijas en el código; usa variables de entorno (`.env` + `.env.example`).
- Consulta las skills en `.agents/skills/` al diseñar capas (`arquitectura-api`) o validaciones y seguridad (`seguridad-api`).
